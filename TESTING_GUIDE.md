# GHOSTKEY 2.0 — Testing guide

## 1. Setup
```bash
cd ghostkey/backend
py -m venv .venv
.venv/Scripts/python -m pip install fastapi "uvicorn[standard]" sqlalchemy pydantic httpx python-multipart opencv-python-headless numpy pytest python-dotenv
copy .env.example .env        # put your DetectifAI key in DETECTIF_API_KEY
cd ../frontend
npm install
copy .env.example .env.local
npm run dev:all               # FastAPI on :8000, Next.js on :3000 → open http://localhost:3000 in Chrome
```

## 2. Automated tests (no live AI service needed)
```bash
cd ghostkey/backend
.venv/Scripts/python -m pytest -q
cd ../frontend
npx tsc --noEmit && npx next build
```
Covers: provider success/errors/timeouts/402 insufficient credits/unexpected schema; upload type, size and
duration limits; API token failures; agent crash handling; conflicting findings; missing mandatory evidence;
expired and replayed challenges; action-bound approvals (incl. 84000 vs 84000.0 normalisation); all four
policy outcomes; every demo scenario; simulated results never labelled live; secrets never returned;
audit-chain tampering; case deletion; single-image exam matches.

## 5. Face verification checks (Exam page, Chrome)
| Case | How | Expected state |
| --- | --- | --- |
| Match | enroll your face, verify 5 live frames | FACE_MATCH_SUPPORTED → VERIFIED (liveness still unproven) |
| Non-match | enroll, then a consenting teammate verifies | FACE_MISMATCH_SUSPECTED → ESCALATED |
| Poor lighting | cover the light / dark room | LIVENESS_INCONCLUSIVE → HOLD |
| No face | point the camera away | NO_FACE_DETECTED |
| Multiple faces | two people in frame | MULTIPLE_FACES_DETECTED → ESCALATED |
| Invalid upload | upload a .txt as an image | 415 unsupported_format |
| Single image | upload one photo | match → HOLD (needs 3 frames) |
Face similarity is **not** liveness testing; there is no presentation-attack model.

## 6. Troubleshooting
- **"GhostKey backend is not reachable"** — start the backend (`npm run dev:all`) and check BACKEND_URL.
- **Camera/microphone blocked** — use Chrome on `http://localhost` and allow the permission (the in-app preview pane blocks devices).
- **Next.js "TypeScript 7 not supported"** — keep `typescript@5.9` (already pinned).
- **SWC blocked by Windows Application Control** — Next falls back to the wasm compiler automatically (first start is slower).
- **402 insufficient_credits** — top up DetectifAI credits; GhostKey never substitutes a result.
- **401 from /api** — the frontend's GHOSTKEY_API_TOKEN must match the backend's.
- **`EINVAL readlink ... .next` on start** — happens on OneDrive after `next build`; delete `frontend/.next` and start again.
